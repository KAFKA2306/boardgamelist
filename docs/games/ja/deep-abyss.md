## 四つの教団による、世界の版図をめぐる抗争

世界の境界は薄れ、四つの秘密教団が姿を現した。各プレイヤーは世界地図状の盤面へ勢力を広げ、眠れる存在の寵愛を競います。

勝利条件は単純です。ゲーム終了時に最も多くの区域を支配した教団が勝利します。区域の見た目の面積にかかわらず、すべて1点です。

## 遊び方

1. 代表者が「部屋を作る」を押し、表示された6文字コードまたは招待URLを共有します。
2. ほかの3人が各自のブラウザから参加します。
3. 4人揃ったらホストが標準ドラフトを開始します。
4. 各プレイヤーは4巡のドラフトで能力カードを4枚獲得します。
5. 開始プレイヤーから時計回りに、隣接侵蝕・遠隔潜伏・教団抗争のいずれか1行動を実行します。

## 基本行動

| 行動 | 対象 | 結果 |
|---|---|---|
| 隣接侵蝕 | 自領に隣接する未支配区域 | 1区域ずつ最大2区域を獲得。1区域目から連鎖可能 |
| 遠隔潜伏 | 自領に隣接しない未支配区域 | 任意の1区域を獲得し、次の自分の手番から起点化 |
| 教団抗争 | 自領に隣接する敵領 | 双方1D6。攻撃側だけが大きければ奪取 |

通常侵攻の成功率は15/36、約41.7%です。同値は防御側が守ります。

## オンライン版の通信仕様

GitHub Pagesは静的ホスティングのため、ゲーム状態は部屋を作ったホストのブラウザが権威サーバーとして管理します。PeerJS Cloudは接続確立のシグナリングに使用し、確立後の状態同期はWebRTC DataChannelで行います。

- ホストがページを閉じると部屋は終了します。
- 観戦者と途中参加は未対応です。
- 同一人物が再読み込みした場合は、同じブラウザの再接続キーで席を復元します。
- 公開プロトタイプのため、不正操作対策や永続保存は実装していません。

## 実装範囲

プロトタイプ v0.1として、40区域マップ、4人ロビー、標準ドラフト、最大7ラウンド、3基本行動、32枚の能力カード、戦闘ダイス、得点・最大領域群判定、試遊ログの同期まで実装しています。

カードの複雑な連鎖処理はオンライン試遊用の自動判定に合わせています。正式版へ進める前に、5試合で文言、20試合でカード強度、50試合以降で開始位置・手番順の勝率を検証してください。
