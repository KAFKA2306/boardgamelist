# 北原千夜のすべて

## 概要

『北原千夜のすべて』は、**6人用の協力型マーダーミステリー**です。中国で2022年にリリースされた作品を日本語化したもので、日本ではミステリーテリングが日本語版を制作し、2026年1月から公演が開始されました。

公開情報では、推理を重視する作品として案内されています。公演情報では所要時間は**約390分（6時間30分）から6〜7時間程度**として扱われており、一般的なマーダーミステリーより長時間のセッションです。
