# BOHNANZA（ボーナンザ）

## このページが対象にする版

このページは、AMIGO Games が現在掲載している **Bohnanza / Item Number 21757** を対象にします。

- 3〜7人
- 13歳以上
- 約45分
- 基本ゲーム: 104枚のBean Cards
- 同梱拡張: 50枚（Cocoa / Wax / Coffee）
- Bean Mats: 7枚

**公式情報:** https://www.amigo.games/product/bohnanza/

25th Anniversary Edition は別版です。2人用variantや25周年版専用要素を、このページの基本ルールへ混ぜません。

## 何をするゲームか

豆を畑に植え、他プレイヤーと交換し、十分に育った畑を収穫してコインを得ます。重要なのは、手札の並び順を自由に変えられないことです。そのため、不要な豆を交換・譲渡して次に植える豆を整える交渉がゲームの中心になります。

## 基本ゲームを始める前に

公式ルールでは基本ゲームを3〜5人で説明しています。6〜7人で遊ぶ場合は、同梱されている追加の豆を使うvariantの人数別セットアップを公式ルールで確認してください。

基本ゲームでは8種類・104枚の豆カードを使います。拡張用のCocoa / Wax / Coffeeなどを基本セットへ無条件に混ぜないでください。

## 1ターンの流れ

基本ゲームのターンは、次の4段階で進みます。

1. 手札の先頭から豆を植える。
2. 山札から公開した豆を、他プレイヤーと交換または譲渡する。
3. 交換・譲渡で受け取った豆を畑へ植える。
4. 山札から新しい豆カードを引き、手札の最後尾へ追加する。

手札の順番を並べ替えないことが、ルール理解で最も重要な点です。

## 収穫と勝利

畑はゲーム中に収穫できます。収穫時は、その豆のBeanometerに従ってコインとして残す枚数を決め、残りを捨て札にします。収穫条件には例外があるため、実際のプレイでは公式ルールの「Harvesting Beans」を確認してください。

基本ゲームは山札が3回目に尽きたときに終了します。終了処理後に各畑を収穫し、コインが最も多いプレイヤーが勝者です。

## 人数による版・variantの違い
