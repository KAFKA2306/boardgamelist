# 深淵侵蝕 Web Prototype

GitHub Pages上で動作する、4人専用のPeer-to-Peer領域支配ゲームです。

## 構成

- `index.html`: ロビー、ドラフト、盤面、戦闘、結果画面
- `cards.js`: 32枚の能力カード、40区域の座標、回転対称の隣接グラフ
- `app.js`: ホスト権威型ゲーム状態、PeerJS同期、ルール判定
- `style.css`: レスポンシブUI

## 通信

ホストは `deep-abyss-<ROOM>` 形式のPeer IDを取得します。参加者は部屋コードからホストへ接続し、意図だけを送信します。ホストが検証・状態更新し、全参加者へスナップショットを配信します。

## 制約

GitHub Pagesは静的ホスティングです。永続化、専用TURN、サーバー権威、不正対策、ホスト移譲は含みません。
